# ENOUGH Web App v1.5 — Research Dashboard

Adds:
- Personal / Research tabs in Insights
- Baseline vs ENOUGH descriptive comparison
- AAG trend on high-urge days
- Overstudy and Successful Stop normalized per 7 logged days
- Sleep protection and Finish-Line Adherence comparisons
- Urge → extra-study descriptive association
- One-page printable Research Summary
- Expanded research CSV export (pilot day, recovery signal, sleep protection)
- Clear interpretation boundaries: prototype metrics, no diagnosis/causal/efficacy claim

All data remains in browser localStorage unless the user explicitly exports it.
